# MoMoShield — fiche portfolio

**Titre** : Détection de fraude Mobile Money en temps réel (données synthétiques)

**Stack** : Kafka, Schema Registry, Spark (profil full), Python streaming (profil core), Airflow, dbt, Great Expectations, PostgreSQL, MinIO, Streamlit, Docker, CI Docker.

**Chiffres à mesurer** : débit evt/s, latence p95, rappel fraudes injectées, nombre checks GE.

**Défis** : classes déséquilibrées PaySim, idempotence `tx_id`, CI sans GitHub Actions.
